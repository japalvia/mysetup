Lazyvim
=======

Differences compared to standard neovim:

text width:
- soft wrap gq cannot be used (due to LSP formatting?)
- use hard wrap gw

find text in files under CWD:
<leader> /

switch to previous buffer:
C-6

save file in any mode(?):
C-s

scroll autocompletion tooltip window (nvim-cmp plugin):
C-f
C-b

Same as neovim but useful:

create new file:
:e %<tab>
:e %:h<tab>

replace visual selection:
c
type new text

go the previous function:
[f

copy text and paste over selection multiple times:
yank visual selection
select target text
select register 0 to paste: "0p

Scratch buffer
-------------
Select from existing:
<leader> - S
Create new:
<leader> - .


quickfix list
-------------

to to prev/next error:
[q
]q

send LSP results to quickfix list:
- inside picker: <C-q>


Plugins
-------

noice: manage messages
- <leader> sn


Markdown
--------

Configured for .md and .uml filetypes. Edit options.lua to add new filetypes for preview

:MarkdownPreviewToggle

When opening puml diagram:
set makeprg=plantuml\ --svg\ %

Generate image:
:make

Repeat last command:
@:


LSP
---

Keymaps:
https://www.lazyvim.org/keymaps#lsp
example: rename symbol under cursor:
<leader> cr

Hover tooltip:
- open: K
- enter the window for navigating: again K

Code actions:
- move cursor to variable / statement
- <leader> ca

LSP errors:
~/.local/state/nvim/lsp.log

rust-analyzer error: "Invalid offset LineCol { ... }"
- triggered at least by deleting all content in file
- workaround: :LspRestart

Open references to quickfix list:
gr to search
C-q to open quickfix list

Type hierarchy (clangd custom extension)
:ClangdTypeHierarchy

LSP references (e.g. incoming and outgoing calls):
<leader> cuS
increase window size: ctrl-left/right

install extras snack picker, then:
gai (incoming calls)
gao (outgoing calls)

search symbols in buffer:
<leader> ss
search symbols in workspace:
<leader> sS

jump to matching bracket:
%

navigate lazyvim dialog window panes:
alt-w
now you can select and yank the message

Copilot
-------

MCPHub integration: gitlab
- current setup uses private MCP server written in python
- can it be replaced with the official server?
- show/add/delete servers: nvim command MCPHub
- copilot chat:
    * MCPHub tools are mapped to functions: calling function produces output that can be prompted again
    * list all opened: @gitlab_custom_get_merge_requests helix/esp
    * show changes: @gitlab_custom_get_merge_request_changes 1763 helix/esp
    * you can now give prompts like "review this merge request"
